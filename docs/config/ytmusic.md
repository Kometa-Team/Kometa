# YouTube Music

Kometa connects to YouTube Music's public data automatically. No sign-in, API key, or `ytmusic` configuration block is needed.

For music collections, use these builders:

- [Public playlists](../files/builders/ytmusic/index.md#youtube-music-list-builder)
- [Top artists by country](../files/builders/ytmusic/index.md#youtube-music-top-artists-builder)
- [Dynamic charts](../files/builders/ytmusic/index.md#youtube-music-dynamic-charts)

YouTube Music can also provide artist artwork for [library operations](operations.md).
These features require a working YouTube Music connection; check the connection message in the Kometa log if they fail.
