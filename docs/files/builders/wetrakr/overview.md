# WeTrakr Builders

You can find items using lists and personal data from [WeTrakr](https://wetrakr.com/).

???+ warning "WeTrakr Configuration"

    [Configuring WeTrakr](../../../config/wetrakr.md) in the config is required for any of these builders.

| Builder                            | Description                                                    | Works with Movies                          | Works with Shows                           | Works with Playlists and Custom Sort       |
|:------------------------------------|:----------------------------------------------------------------|:------------------------------------------:|:------------------------------------------:|:------------------------------------------:|
| [`wetrakr_list`](list.md)          | Finds every item in a WeTrakr list.                             | :fontawesome-solid-circle-check:{ .green } | :fontawesome-solid-circle-check:{ .green } | :fontawesome-solid-circle-check:{ .green } |
| [`wetrakr_user_lists`](list.md)    | Finds every item across a WeTrakr user's public lists.          | :fontawesome-solid-circle-check:{ .green } | :fontawesome-solid-circle-check:{ .green } | :fontawesome-solid-circle-check:{ .green } |
| [`wetrakr_tracking`](personal.md)  | Finds items in the configured WeTrakr account's tracking list, filtered by status. | :fontawesome-solid-circle-check:{ .green } | :fontawesome-solid-circle-check:{ .green } | :fontawesome-solid-circle-check:{ .green } |
| [`wetrakr_favorites`](personal.md) | Finds every item in the configured WeTrakr account's favorites. | :fontawesome-solid-circle-check:{ .green } | :fontawesome-solid-circle-check:{ .green } | :fontawesome-solid-circle-check:{ .green } |
| [`wetrakr_ratings`](ratings.md)    | Finds every item the configured WeTrakr account has rated.      | :fontawesome-solid-circle-check:{ .green } | :fontawesome-solid-circle-check:{ .green } | :fontawesome-solid-circle-check:{ .green } |
